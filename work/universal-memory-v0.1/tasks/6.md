# Task 6: CloudAdapter against real Postgres + pgvector

## Description

Cloud mode has never touched a database. `cloud.test.ts` asserts only what happens when
`DATABASE_URL` is unset; `cloud.unit.test.ts` runs against a mock engine — and a mock
engine is exactly what hid the fictional-API defect described in decisions F2. Half the
product's storage story is unverified.

## What to do

- Add an integration suite driving `CloudAdapter` against a real Postgres 15+ with
  pgvector: `add` → `getById` → `list` → `search` → `delete` → `clear`, mirroring the
  real-PGLite suite in `local.unit.test.ts`.
- Provide the database through `docker-compose` for local runs and a service container
  in the continuous integration workflow from task 1.
- Cover `migrateAttestationsTable()` against the real database, not a stubbed `db.query`.
- Per decision D3, when `DATABASE_URL` is absent the suite skips with an explicit line
  naming it.
- While here, confirm the mocked `cloud.unit.test.ts` still reflects the real engine
  surface; if the integration suite reveals a divergence, fix the mock rather than
  leaving two contradictory descriptions of the same object.

## TDD Anchor

- `cloud_adapter_round_trips_against_real_postgres` — full cycle, real database.
- `cloud_adapter_search_returns_scored_results` — assert the mapped shape
  (`id`/`content`/`score`) comes back from a real query, not a fixture.
- `migrate_attestations_table_is_idempotent` — run it twice against the real database,
  assert no error and one table.
- `cloud_suite_skips_loudly_without_database_url` — no silent pass.

## Acceptance Criteria

- [ ] An integration suite exercises `CloudAdapter` against real Postgres + pgvector
- [ ] The full add → getById → list → search → delete → clear cycle passes
- [ ] `migrateAttestationsTable()` is verified against the real database and is idempotent
- [ ] Absence of `DATABASE_URL` produces a visible skip
- [ ] The database is available locally via `docker-compose` and in continuous integration
- [ ] Any divergence found between mock and reality is fixed in the mock
