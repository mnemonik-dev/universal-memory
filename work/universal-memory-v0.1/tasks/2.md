# Task 2: Self-hosted embeddings + semantic search proven

## Description

Semantic search is the product, and it has never run. Every suite and every smoke run so
far has been BM25-only: with no embeddings provider configured, `embeddingsEnabled` is
false, `add()` stores with `noEmbed`, and `search()` takes `engine.searchKeyword`
instead of `hybridSearch`. In a perimeter that forbids sending documents to third
parties, the only acceptable provider is one we host ourselves.

## What to do

- Run Ollama on the deployment host with `nomic-embed-text` pulled, plus a chat model
  for `memory_think`. `config.ts` already probes `OLLAMA_BASE_URL` and wires
  `ollama:nomic-embed-text` — configure it, do not rewrite it.
- Confirm the running server reports `provider=ollama` at startup and that
  `embeddingsEnabled` is true, so `hybridSearch` is the path actually taken.
- Add an integration test that proves semantic retrieval: store a document, retrieve it
  with a query sharing no significant terms with it. That single assertion is the point
  of the task — it is exactly what keyword search cannot do.
- Assert the negative too: with no provider, the suite skips with a visible line naming
  the missing variable. It must never silently pass in keyword mode (see D3).
- While the semantic test runs, confirm no outbound request leaves the host to any
  third-party API. Record how that was checked.
- Measure and record what the model costs the host in memory and latency. If it does not
  fit, choose a smaller embedding model and record that — never fall back silently.

## TDD Anchor

- `semantic_query_with_no_shared_terms_finds_document` — store "The feline rested on the
  woven floor covering", query "cat sleeping on a rug", assert the hit. Must fail if
  forced onto `searchKeyword`.
- `embeddings_disabled_skips_loudly` — no provider set produces a skip, not a pass.
- `stored_chunks_carry_vectors` — capture with the provider present stores embeddings,
  not text alone.

## Acceptance Criteria

- [ ] The deployed server runs with a self-hosted embedding provider
- [ ] A no-shared-terms semantic query retrieves the right document
- [ ] That test fails when forced onto the keyword path (verify, then revert)
- [ ] No third-party API is contacted during embedding or search; how this was verified
      is written down
- [ ] Absence of a provider produces a visible skip, never a silent pass
- [ ] Host resource cost and any model substitution are recorded in `decisions.md`
